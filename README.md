## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn or pnpm

### Installation & Run

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
